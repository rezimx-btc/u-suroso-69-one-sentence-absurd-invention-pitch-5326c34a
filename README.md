## How to run

```bash
python3 main.py
```

Prints exactly one sentence to stdout and nothing else. Python 3.13, standard library only, no file I/O, no network, fully deterministic.

## The pitch

> Meet the Sock Reunion Drone, which patrols the laundry room, sniffs out lonely socks and escorts them home while wearing a tiny high-visibility vest and honking twice before every takeoff.

(188 characters, one sentence.)

## Why it fits the brief

The pitch names a concrete invention (the Sock Reunion Drone), says exactly what it does (patrols the laundry room and reunites lost socks), and lands one specific, visual absurdity — a drone in a tiny high-visibility vest honking twice before every takeoff, as if a sock rescue were a runway operation. It solves the most mundane everyday annoyance — the sock that vanishes in the wash — in the most over-engineered way possible, with no AI hand-waving and no generic smart-appliance joke.
